# مدیریت مرکزی با پنل وب Hub

**RatholeHub** پنل وب تک‌فایلی (Python 3 استاندارد، بدون pip) است که مدیریت چند سرور ایران/خارج را از طریق SSH (بدون agent) متمرکز می‌کند. راهنمای کامل و مرجع API: [`../hub.md`](../hub.md)

## نصب و دسترسی

```bash
sudo ratholectl hub on 2087      # نصب خودکار در اولین اجرا
# → https://<دامنه>/hub/
# دسترسی بدون پورت: ssh -L 2087:127.0.0.1:2087 root@<panel> → http://localhost:2087
```

* در نصب اول، رمز ادمین **از tty** پرسیده می‌شود و با PBKDF2 ذخیره می‌شود؛ کلید SSH هاب در `/etc/ratholehub/id_ed25519` ساخته می‌شود.
* تغییر پورت بعداً: `sudo ratholectl hub on <port>` · تغییر مسیر: `sudo ratholectl set hub-path <seg>`
* خاموش کردن (سرویس حفظ می‌شود): `sudo ratholectl hub off`

## گردش‌کار پیشنهادی

1. **ورود:** رمز ادمین → توکن API در UI ذخیره می‌شود.
2. **ثبت سرور ایران:** Servers → Add (role=iran، host پنل).
3. **Provision نود:** Servers → Provision (role=node) + رمز SSH → نصب کلید هاب + دیپلوی اسکریپت‌ها + ثبت (برای چند دقیقه صبر کنید؛ نتیجه در audit ثبت می‌شود).
4. **مدیریت از صفحه سرور:** overview زنده (نسخه‌ها، سرویس‌ها، doctor) + اکشن‌ها (restart/regen/logs/update/سوییچ ترنسپورت/...).
5. **تنظیمات:** تغییر رمز (همه نشست‌ها می‌بندد) · rotate توکن (Bearerهای قدیمی می‌میرند) · ssh_opts.

## امنیت (خلاصه — جزئیات در ../hub.md)

* ورود: PBKDF2 + محدودیت ۵ تلاش/۳۰۰ ثانیه per-IP (اتمیک).
* نشست: کوکی `HttpOnly; SameSite=Strict; Secure` — **تغییر رمز = ابطال فوری همه نشست‌ها**.
* فقط کلید SSH هاب؛ whitelist برای ssh_opts؛ audit کامل (0600) با redaction.
* هاب روی `127.0.0.1` گوش می‌دهد؛ دسترسی عمومی فقط پشت nginx TLS.

## نکته: مدیریت وقتی پورت 22 فیلتر است

هاب می‌تواند به خودِ پنل از مسیر loopback هم SSH بزند: در UI، host سرور ایران را روی `127.0.0.1` ویرایش کنید (`PUT /api/servers/<n> {"host":"127.0.0.1"}`) — اکشن‌ها بدون دسترسی بیرونی به 22 کار می‌کنند (تست‌شده).
